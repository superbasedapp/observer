04b / STORY STAGES

Product screenshots are used once, in the hero. Every other claim is a story stage: a sticky panel whose frames are scrubbed by scroll position, so the visitor's scroll IS the passage of time. A stage earns its space only if it has a before, a turn, and an after — decorative loops don't qualify. Two per page, spaced far apart, never stacked.

05 / RULES

Do / don't

DO
One accent per theme — blue in Blueprint, amber in Phosphor.
Headline plus one line. Let the screenshot carry the detail.
Separate with 1px lines and 1px grid gaps, not cards and radii.
Number every section eyebrow: 01 /, 02 /, 03 /.
Set numbers, labels and commands in mono; prose in Grotesk.
DON'T
Don't run teal, gold and red together — that was the old drift.
No gradients as backgrounds, no blurred drop shadows, no rounded corners.
No seven-line grey paragraphs above the fold.
No emoji, no hand-drawn illustration, no stock iconography.
Don't state a claim twice in one viewport (license, tool count).
Implementation note: tokens ship as CSS custom properties on the page root, light values inline and [data-theme="dark"] overriding them. This replaces the split between assets/css/home.css and assets/css/site.css — one token layer, both layouts.
